# 👤 User Guide

Welcome to **RahatVerse** — the interactive portfolio and website-ordering platform
of Rahat Ahmed.

## Browsing

- **Language:** switch between **বাংলা** and **English** using the language toggle.
- **Navigation:** use the top navbar (and the bottom navigation on mobile).
- **Dark/Light mode:** toggle the theme; you can also change the accent color via
  the theme customizer.
- **Search:** use the search icon to find content across the site.
- **Save for later:** bookmark posts/sections (requires login).

## Main sections

- **About** — biography, education, achievements.
- **Services** — the services offered (web development, tutoring, etc.).
- **Gallery** — photo gallery with categories and lightbox.
- **Portfolio / Projects** — detailed case studies.
- **Blog** — articles, filterable by category.
- **Achievements** — awards and milestones.
- **Links** — all social links in one place (Linktree-style).
- **Contact** — send a message.
- **Sitemap** — a visual map of the whole site.

## Ordering a website

1. Go to **Order**.
2. Follow the multi-step wizard (choose a package/plan, add details).
3. Submit; you can track your order status on the **Order tracking** page.
4. You may be contacted via WhatsApp or email for confirmation.

## Newsletter

1. Enter your email in the **Newsletter** signup box (home page footer).
2. Click the confirmation link in the confirmation email (valid for 48 hours).
3. Manage or unsubscribe via links in any newsletter email.

## Contacting

Use the **Contact** form. If you need urgent help (e.g. blood donation), use the
**Blood request** form so the admin can act quickly.

## Account (optional)

- Create an account to use **Save for later** (bookmarks) and personalization.
- Log in via **Login** (email/password, Google, or magic link).
