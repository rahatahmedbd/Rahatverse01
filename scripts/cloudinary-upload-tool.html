☁️ RahatVerse — Cloudinary ছবি আপলোড

পুরনো ওয়েবসাইটের ১৪টি ছবি আপনার Cloudinary অ্যাকাউন্টে আপলোড হবে। শুধু API Secret দিয়ে বাটনে ক্লিক করুন।

🔒 নিরাপত্তা: এই পেজটি সম্পূর্ণ আপনার ব্রাউজারে চলে। API Secret কোনো সার্ভারে যায় না — সরাসরি ব্রাউজার থেকে Cloudinary-তে (HTTPS) পাঠানো হয়। পেজ বন্ধ করলেই সব মুছে যায়।
